# 文件备份系统需求说明

## 1. 项目目标

开发一个面向 Windows 桌面用户的文件备份工具。用户可以选择源目录与备份位置、设置筛选规则、执行或定时执行备份，并在需要时将备份还原到指定目录。

当前版本以课程演示所需的可靠性、可理解性和模块化为优先目标，不包含云存储、跨设备同步、文件加密和企业级权限管理。

## 2. 用户角色

系统仅定义一个本地用户角色。用户拥有本机文件系统授权范围内的全部备份、还原、筛选和定时任务操作能力。

## 3. 功能需求

| 编号 | 需求 | 验收条件 |
| --- | --- | --- |
| FR-01 | 选择备份源目录 | GUI 可选择一个存在且可读取的目录；无效目录会得到明确提示 |
| FR-02 | 选择备份目标目录 | GUI 可选择或创建目标目录；不可写时禁止开始备份 |
| FR-03 | 完整备份 | 首次备份可复制所有符合筛选条件的文件，并保留相对目录结构 |
| FR-04 | 增量备份 | 仅复制相对上次成功备份后新增或发生变化的文件 |
| FR-05 | 差异备份 | 仅复制相对最近一次完整备份后新增或发生变化的文件 |
| FR-06 | 文件筛选 | 支持按扩展名、排除路径、大小和隐藏属性筛选 |
| FR-07 | 进度反馈 | 备份和还原过程中显示阶段、当前路径、文件数量及字节进度 |
| FR-08 | 取消操作 | 用户可请求取消长任务；系统在安全边界停止并返回取消状态 |
| FR-09 | 文件还原 | 可将备份内容还原到指定目录，并重建原有相对目录结构 |
| FR-10 | 冲突处理 | 还原遇到同名文件时支持覆盖、跳过和重命名三种策略 |
| FR-11 | 定时备份 | 支持创建、启用、禁用和删除本地定时任务 |
| FR-12 | 结果报告 | 操作结束后显示成功、取消或失败状态，以及已处理/跳过文件统计 |

## 4. 非功能需求

- **兼容性**：Windows 10/11，Qt 6 Widgets，MinGW-w64，C++17。
- **可维护性**：GUI、筛选/调度、备份/还原之间通过公共接口通信，核心层不依赖 Qt。
- **响应性**：目录扫描、复制、校验和还原不得阻塞 GUI 主线程。
- **可靠性**：单个文件失败应产生可定位的错误信息；不能把部分完成误报为成功。
- **路径处理**：使用 `std::filesystem::path` 保存路径，不通过窄字符串手工拼接 Windows 路径。
- **可测试性**：目录遍历、筛选、冲突策略和结果统计应能脱离 GUI 单独测试。

## 5. 数据与状态约定

- 只有完整成功的任务可作为后续增量/差异备份的基线。
- 备份目录包含描述来源、时间、模式和文件清单的元数据，格式由核心模块实现并通过公共接口与其他模块衔接。
- `maximumFileSize == 0` 表示不限制最大文件大小。
- 取消是正常终止状态，不作为 I/O 错误处理。
- 用户输入路径在任务开始前完成存在性、可读性、可写性和源/目标嵌套检查。

## 6. 课程演示验收流程

1. 准备含子目录、普通文件和可筛选文件的测试目录。
2. 执行一次完整备份，展示目录结构和进度变化。
3. 修改、新增文件后执行增量备份，确认未变化文件未重复复制。
4. 使用排除扩展名规则再次备份，确认筛选生效。
5. 删除原目录中的一个测试文件，从备份还原并验证内容。
6. 演示一种同名冲突策略和一次取消操作。
7. 创建短周期定时任务并展示自动触发记录。

## 7. 暂不纳入范围

- 云盘、FTP、NAS 专用协议和多设备同步
- 文件压缩、加密、去重和块级增量
- Windows 服务、管理员权限提升和系统级灾难恢复
- 多用户账户、远程管理和集中审计

## 8. 当前实现状态

FR-01 至 FR-12 均已在桌面程序中实现。自动化测试覆盖筛选、调度持久化、三种备份模式、备份链还原、空目录和冲突策略；GUI 已完成构建和启动冒烟验证。定时备份依赖程序保持运行，不注册 Windows 服务。

## 9. 本次验收修订

- FR-13：定时任务可设置保留最新 N 份成功快照，0 不限制；仅处理同源同名快照并保留依赖链。
- FR-14：界面和磁盘记录操作结果及跳过事件，自动任务不弹出阻塞对话框。
- 自定义备份支持路径、扩展名类型、名字通配符、修改时间区间、尺寸；尚无用户属主筛选。
- 定时任务保存到程序旁 settings；自动任务只在应用运行时执行。
- GUI 周期工作流已通过真实 1 分钟间隔两次触发和淘汰验证，见交付根目录核验与调试报告。

## 10. 名字与时间筛选补充验收

- 名字包含/排除规则只匹配文件名，支持自编 UTF-8 通配符匹配：* 任意长度、? 一个字符；多规则以分号分隔，包含取或、排除优先。
- 修改时间可独立启用起始、截止，按本机显示时间填写，包含边界秒。起始晚于截止拒绝执行和创建定时任务。
- 五个筛选维度取交集。目录不受名字/时间限制，避免剪掉有匹配文件的子树。
- 定时任务持久化新规则及可选时间边界；旧版任务无这些字段时保持不限制，清除条件后不得残留。
- 增量备份在放宽筛选后，应复制新入选且原快照没有保存的文件，并能沿链还原。

## 11. 打包 / 解包验收补充

- FR-15：将具体快照导出为单个 DBPACK v1 文件，保留内容、相对目录、空目录及还原所需元数据。增量/差异快照自动补齐数据并消除外部父链依赖。
- FR-16：解包先校验条目及内容，再导入为新的独立完整快照，并可在 GUI 还原。不覆盖已有包或旧快照。
- FR-17：拒绝损坏/截断/尾随垃圾包、重复或不安全路径。取消/失败清理自建暂存输出，不误报完成。
- UI 追加“打包/解包”页，后台工作线程执行，支持进度、日志和取消。成功后自动衔接到解包和还原路径。

## 12. 备份统计口径

成功备份的 skippedFiles = filteredFiles + unchangedFiles。筛选排除数包括被排除子树中可统计的普通文件；目录本身和符号链接不当作普通文件计数。排除路径不可读时保留 uncountedExcludedPaths 并提示内部未统计，不因它已经被排除而使备份失败。结果弹窗及执行日志区分筛选排除和未变化免复制。还原跳过数仍表示冲突策略跳过。
