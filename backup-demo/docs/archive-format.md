# DBPACK v1 单文件格式与独立快照

## 字节布局

所有整数均为无符号小端。文件头为 8 字节 ASCII `DBPACK01` 和 uint64 条目数。随后每项依次为 uint8 类型（1 文件、2 目录）、uint32 UTF-8 路径字节数、uint64 内容字节数、uint64 FNV-1a 校验值、路径字节和内容字节。目录长度与校验值必须为 0；零字节文件校验值为 FNV 初值 14695981039346656037。FNV 每字节异或再乘 1099511628211，按 uint64 模运算。

## 导出

1. 校验具体备份快照和清单；拒绝将包写入该快照内部，拒绝覆盖已有包或同名 partial。
2. 在输出父目录创建独有暂存目录。调用既有还原核心，逐字节校验并补齐完整/增量/差异链中的数据。
3. 写入完整清单，将元数据模式改为 Full 并清空父链。
4. 扫描暂存目录，计算校验值并顺序写入包；再次检查读取长度与校验值，防止打包输入在复制时变化。
5. 关闭输出并检查写入成功，最后提交文件；失败/取消清理自建暂存目录和 partial。

## 导入

校验标识、数量、大小、路径以及条目 FNV 值，只允许 backup.meta、manifest.tsv、data 目录及其后代。不信任包内路径，拒绝绝对路径、..、重复路径、设备名、备用数据流以及越界输出。声明内容长度不得超过剩余实际包长度，尾随垃圾也拒绝。

所有文件先解到新暂存目录，核对清单目录、文件和大小，要求元数据为 Full 且无父备份，最后将暂存目录提交为新的独立快照。原有目标文件不被覆盖。

## 范围

最多 100000 个条目，路径最多 16384 UTF-8 字节；标准库实现，不调用 ZIP/7z/归档库。不压缩、不加密；FNV 是意外损坏检测，不是密码学认证。导出需要完整快照的额外暂存空间。
