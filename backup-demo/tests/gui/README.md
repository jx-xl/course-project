# GUI 工作流测试

GuiWorkflowTest.cpp 实例化 MainWindow，操作备份、还原和定时任务控件，检查真实文件内容。新版还验证名字包含/排除、修改时间和原类型/路径规则组合，拒绝反向时间区间。定时任务设置 1 分钟周期、保留 2 份；实际等待两次触发并断言最旧快照淘汰，同时检查自动任务不弹窗。

CTest 名称为 backup.gui.periodic_workflow，约需 65 秒，超时 110 秒（包含桌面定时器延迟余量）。测试使用独立 QSettings 和临时源/仓库，不使用用户的任务。

设置 BACKUP_TEST_ARTIFACT_DIR 可保存四页截图和名字/时间筛选区域截图、打包页、解包后还原及日志截图和本次 GUI 日志。任务操作可独立于用户当前桌面完成。

新版工作流在原有周期测试完成后，继续操作打包导出、校验解包和解包快照还原，检查中文文件内容及路径自动填入。窗口中的路径用文件系统等价性判断，兼容 Windows 正反斜线。

新版还断言结果日志包含“筛选排除 4 个文件”，以确认 UI 显示筛选统计。
